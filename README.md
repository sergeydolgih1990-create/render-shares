# render-shares

Публичные подборки AI-генераций мастерской Lobaro для показа конкретным людям по прямой ссылке.

Ничего не листается — каждая подборка живёт на своей странице `shares/<слаг>/`, ссылку на которую нужно получить отдельно. Собирается скриптом `make_share.py` из приватного [`render-archive`](https://github.com/sergeydolgih1990-create/render-archive).
